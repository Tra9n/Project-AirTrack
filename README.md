# Project-AirTrack

Курсовая работа: система мониторинга самолётов через внешние API.

## Описание

Приложение собирает данные о самолётах в воздушном пространстве заданной страны.

## Возможности

- Получение данных по названию страны
- Сохранение в JSON
- Топ-N по высоте

## Установка

```bash
git clone https://github.com/your-username/Project-AirTrack.git
cd Project-AirTrack
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` и укажите контакт:

```env
NOMINATIM_CONTACT=your-email@example.com
```

> Файл `.env` не попадает в Git.

## Запуск

```bash
python main.py
```
